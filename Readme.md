# DCOMP320 Data Structures and Algorithms
## Stack-Based Mathematical Expression Evaluator

### 1. Project Overview

This project implements a Stack data structure in Python and uses the stack to evaluate mathematical expressions.

The program reads mathematical expressions from an input file, evaluates them according to operator precedence and parentheses, and writes the calculated results to an output file.

### 2. Objectives

The main objectives of this project are to:

- Implement a Stack data structure.
- Demonstrate Stack operations such as push, pop, and peek.
- Use stacks to evaluate mathematical expressions.
- Apply operator precedence when evaluating expressions.
- Read expressions from `input.txt`.
- Write calculated results to `output.txt`.

### 3. Technologies Used

- Python 3
- Python built-in file handling
- Stack data structure
